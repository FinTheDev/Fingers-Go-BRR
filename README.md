# Fingers Go BRR

Fingers Go BRR is a modern, customizable multiplayer typing race game built in Python.
Inspired by clean, minimal typing tools, but built from scratch.

## Features
- real-time wpm & accuracy
- deep customization
- local accounts
- multiplayer races (wip)

## Tech stack
- python
- pywebview
- fastapi
- websockets

## Run locally
```bash
pip install -r requirements.txt
python client/app.py
